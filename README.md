# Hands-on Deep Learning
Study notes: hands-on PyTorch implementations of core deep learning models, from perceptrons to sequence models and GANs.

| Folder | Contents |
|---|---|
| `Perceptron/` | Logic gates with a single-layer perceptron, XOR with an MLP, digit and MNIST classification |
| `CNN/` | Conv/pooling shape walkthrough, CNNs on MNIST and CIFAR-10 (with augmentation), deeper CNN, feature-map visualization, notes on accuracy improvements |
| `RNN/` | Vanilla and bidirectional RNN basics, character-level RNN ("apple" → "pple!") |
| `LSTM/` | LSTM cell implemented from scratch, applied to MNIST |
| `GAN/` | Conditional GAN (CGAN) on MNIST |
| `NLP/` | Tokenization, stop-word removal, POS tagging and NER with NLTK / KoNLPy |
| `Time_series_data/` | LSTM and GRU sine-wave prediction |
| `Install_package/` | NumPy, Pandas, Matplotlib basics |
| `ML_Workflow.ipynb` | Notes on the ML workflow, from data collection to deployment |
